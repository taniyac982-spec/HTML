44. Explain the difference between a pseudo-class and a pseudo-element using practical examples such as :hover and ::before.

A pseudo-class is used to style an element when it is in a particular state. For example, :hover works when the mouse pointer is over an element.

A pseudo-element is used to style a specific part of an element or add extra content. For example, ::before can add content before an element's text.

Example:

In simple words: :hover = state of an element, ::before = part or generated content of an element.

300px + 20px + 20px + 2px + 2px = 344px
